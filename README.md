# Глубины Рубежа — **alpha 0.3.0.0 «Три Стража»**

Карточная roguelike в сеттинге **Легенды Рубежа**. Десктоп-приложение на **Pygame**.

## Новое в 0.3.0.0

- **Три архетипа:** Стальной, Теневой и **Пламенный** Страж (+12 эксклюзивных карт)
- **5 актов** — финал «Сердце Пустоты» с фазами босса
- **Вознесение I–V** после первой победы
- **Благословения** — выбор бонуса после каждого босса
- **Элитные аффиксы** — броня, шипы, реген, вампиризм
- **Узлы «Сокровище»** на карте
- **Ожог** — новый статус урона со временем
- Охотники Рубежа, +10 карт, +5 реликвий, новые события
