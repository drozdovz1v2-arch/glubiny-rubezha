# Глубины Рубежа

Карточная roguelike в сеттинге **Легенды Рубежа**. Десктоп-приложение на **Pygame**.

Репозиторий: https://github.com/drozdovz1v2-arch/glubiny-rubezha

## Запуск

```bash
cd Desktop\glubiny-rubezha
pip install -r requirements.txt
python main.py
```

Или `run.bat`.

## Управление

| Контекст | Клавиши |
|----------|---------|
| Меню | **Enter** — продолжить или новый забег |
| Карта | **ЛКМ** — узел, **перетаскивание** — сдвиг карты |
| Бой | **1–9** — карта, **Z/X/C** — зелья, **Tab/клик** — цель, **Esc** — в меню (ход завершается автоматически) |
| Награда | **1–3** — карта, **S** — пропустить |
| Реликвия | **1–3** — взять, **S** — отказаться |
| Лавка | **1–6** — купить, **H** — лечение, **R** — удалить, **Q/Esc** — уйти |
| Привал | **1** — лечение, **2** — улучшение, **3** — удаление, **4** — сварить зелье (−60 зол.) |
| Событие | **1–2** — выбор |
| Новый акт | **Enter** — вперёд |
| Победа/поражение | **Enter** — новый забег, **M** — меню |
| Колода (оверлей) | **←/→** — страницы, **Esc** — закрыть |
| Кодекс | **1/2/3** — вкладки, **Esc** — назад |

## Сложность

| Параметр | Рубеж | Суровый Рубеж | Кошмар |
|----------|-------|---------------|--------|
| HP игрока | 70 | 58 | 48 |
| Множитель HP врагов | x1.0 | x1.35 | x1.5 (+ за акт) |
| Давление Рубежа | с 5-го хода | с 5-го | с 4-го |

## Особенности

- **4 акта**: лес → пустыня → лёд → руины. Финальный босс — Владыка Пустоты
- **Зелья** (до 3 слотов, по 3 использования): лавка, элиты, привал (−60 зол.), события
- **Лор** — тексты между актами, эпилог победы и фразы поражения
- **Статусы**: яд, слабость, уязвимость — с карточками очистки и синергиями
- **Клятвы** — опциональный модификатор обычного забега (меню)
- **Ежедневный забег** — один сид и модификатор дня
- Реликвии, улучшение и удаление карт на привале и в лавке
- Автосохранение забега — «Продолжить» в меню
- Коллекция артефактов, карт и зелий; 20+ достижений
- Обучение из 12 шагов (можно повторить в меню)
